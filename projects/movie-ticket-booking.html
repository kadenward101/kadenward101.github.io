Movie Ticket Booking System

This project is a Python-based movie ticket booking application, which makes use of a client-server system architecture. This allows users to interact with a GUI, and for the server script to handle database interactions, such as ticket sales and client connections. The GUI client script also contains an admin interface to allow the adding, deleting, and updating of movie details.
